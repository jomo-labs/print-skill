/print

Give your agent the ability to make beautiful printables github.com/jomo-labs/print-skill

Ask a model for “printable HTML” and you get a web page — ink-hungry fills, backgrounds that vanish in the print dialog, content clipped at the sheet edge. This skill packages print as a design discipline. One request in, one print-ready page out.

This very page is set in the skill’s design system: a letter sheet, real margins, ink-only color. Go ahead — print it.

Install in one line
$ npx skills add jomo-labs/print-skill
> make me a weekly chore chart for Maya (9) and Leo (6)
…then just ask. That’s the whole workflow.

Built for paper

Ink-friendly, grayscale-safe, inside the margins real printers can reach. WYSIWYG: the on-screen sheet and the printed sheet are 1:1.

20+ page types

Worksheets with answer keys, chore charts, certificates, calendars, meal plans, scorecards, word searches, comic scaffolds, and a catch-all for everything else.

Themeable in one phrase

“…in the style of Dog Man” restyles fonts, palette, page chrome, even the writing voice — while the print rules hold.

Interactive output

Served pages get a Print / Save PDF button, double-click text editing with undo/redo, and a FIX button when content outgrows its sheet — the page hands the problem back to your model.

Deterministic PDFs

A bundled local server renders pixel-identical PDFs with headless Chromium on every machine. Without it, pages still print fine via the browser dialog.

Tiny footprint

Markdown instructions, a small page shell, an optional local Node server. No build step, no cloud. Works in any skills-compatible agent.

Headless, too

No UI required end to end — the agent authors the page, the PDF renders without a browser or a click. Ready for pipelines that format something printable and ship it onward.

# one-shot: writes the PDF and exits
node server/render-cli.mjs out/chore-chart.html
