A skill for your agent · vol. 1

/print

Give your agent the ability to make beautiful printables github.com/jomo-labs/print-skill

Some things belong on paper — the chore chart on the fridge, the worksheet on the desk, the certificate on the wall. /print takes you straight there: describe the page you want, and your agent comes back with a beautifully set sheet, ready for the printer.

This very page is set in the skill’s design system: a letter sheet, real margins, ink-only color. Go ahead — print it.

Install in one line
$ npx skills add jomo-labs/print-skill

How to use

/print a weekly chore chart for Maya (9) and Leo (6)
/print this recipe, big type, something for the kitchen wall
/print an ocean-animals word search for a 7-year-old
/print a certificate for the World’s Okayest Dog
…and anything else you can describe. That’s the whole workflow.

Reliably print-ready

Ink-friendly, grayscale-safe, inside the margins real printers can reach. And WYSIWYG: the sheet on screen is exactly the sheet that prints, identical on every machine.

Works anywhere

Markdown instructions, a small page shell, an optional local Node server. No build step, no cloud — works in any skills-compatible agent.

Interactive mode

Double-click any text to edit it, undo and redo, save an exact PDF with one click — and when content outgrows its sheet, a FIX button hands the layout straight back to your agent.

Headless mode for your agents

No clicks, no browser: pages author and render to PDF entirely in the pipeline, ready to email, archive, or send to print.

20+ page types

Worksheets with answer keys, chore charts, certificates, calendars, meal plans, scorecards, word searches, comic scaffolds, and a catch-all for everything else.

Theme-ready

“…in the style of Dog Man” restyles fonts, palette, page chrome, even the writing voice — while the print rules hold.
