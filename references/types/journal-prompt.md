# Journal / writing prompt page

Part of the print skill's page-type catalog. `references/page-types.md`
holds the routing table, the shared **content blocks** this spec names
(section block, checklist block, lined writing area, …), the sheet
geometry, and the theming rule: on a themed request, *Default styling*
below is dropped entirely and only *Functional requirements* survive.

**Portrait.** Keep it quiet and uncluttered — this page is mostly paper.

*Functional requirements:* a dated prompt above a generous **lined writing
area** (28px adult row spacing / 36px kids). Optionally a small quote or mood
row.

*Default styling:* prompt centered display `--text-lg`; rules in
`var(--color-rule-light)` at `--border-hair`.
